# django_blog

Блог на Django с публичной веб-частью и REST API.

## Возможности

**Сайт**
- Лента статей с пагинацией (по 4 на страницу)
- Категории статей, сортировка списка
- Страница статьи: полный текст, счётчик просмотров (считается по сессии, чтобы не расти от повторных заходов), комментарии
- Лайки и дизлайки к статье
- Поиск по названию статей, с историей поиска для вошедших пользователей
- Регистрация, вход, выход
- Профиль автора: его статьи, количество статей и комментариев
- Создание, редактирование и удаление статей с превью-картинкой

**REST API** (`/api/`)
- Категории, статьи, комментарии — `ModelViewSet` (список, создание, просмотр, изменение, удаление)
- Регистрация и вход по токену (`/api/register/`, `/api/login/`)
- Фильтрация статей по категории и автору, сортировка по просмотрам и дате
- Автоматическая документация: `/api/docs/` (Swagger), схема — `/api/schema/`

## Стек

Python, Django 5, Django REST Framework, django-filter, drf-spectacular (Swagger), SQLite, Pillow (обработка изображений), Bootstrap.

## Запуск

```bash
git clone https://github.com/listochek17/django_blog.git
cd django_blog

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/ · Админка: http://127.0.0.1:8000/admin/ · API-документация: http://127.0.0.1:8000/api/docs/

## Структура

| Папка | Назначение |
|-------|-----------|
| `blog/` | настройки проекта Django, корневые маршруты |
| `blog_app/` | модели (статьи, категории, комментарии, лайки/дизлайки, история поиска), веб-страницы |
| `blog_api/` | REST API: сериализаторы, вьюсеты, маршруты |
| `templates/`, `static/` | общие шаблоны и статика |
| `schema.yaml` | сохранённый снимок схемы API |

## Модели

- **Category** — категория статьи
- **Article** — статья: автор, категория, превью, счётчик просмотров, слаг из названия
- **Comment** — комментарий к статье
- **ArticleViews** — учёт уникальных просмотров по сессии
- **SearchHistory** — история поисковых запросов пользователя
- **Like / Dislike** — реакции на статью
- **Todo** — задачи пользователя (модель есть, страниц под неё пока нет)
